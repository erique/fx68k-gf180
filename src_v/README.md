# sv2v-converted Verilog

Generated by `make sv2v`. Do not hand-edit.

- `fx68k.v` — patched copy of `../src/*.sv` through sv2v
- `uRom.v` / `nanoRom.v` — synchronous ROMs from `src/microrom.mem` / `nanorom.mem`

`scripts/run-sv2v.sh` rewrites `rowDecoder`'s block-local `stype` reg into a
combinational expression so Yosys does not infer a latch. ROM `$readmemb`
modules are dropped from `fx68k.v`; contents are the generated `uRom` /
`nanoRom` files.
